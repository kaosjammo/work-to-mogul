# Art Generation / Implementation Audit

Generated by comparing `src/content/artManifest.ts`, the content catalogs, and
the files under `public/assets/`.

The game still degrades gracefully if future content is added without art:
`ui/shared/art.ts` falls back to category SVGs or emoji, and
`src/content/artManifest.test.ts` verifies that every authored manifest path
exists.

_Last audited: post art-wiring pass (industry banners + patterns now rendered)._

## Referenced-but-missing asset ids

**None.** Every path currently authored in `src/content/artManifest.ts` resolves
to a real SVG under `public/assets/`.

## Optional / Still Emoji-Based by Design

These systems remain intentionally emoji-based. They are readable and do not
block gameplay or current UI polish:

- Prestige talents.
- Ascension milestones.
- L5 specialisations.
- Contracts board.
- Golden Deal / Time-Warp floating button.
- Empire Token glyph.
- Rarity/fusion embellishments.

Future art passes can brand these, but they are no longer part of the active
missing-art list.
