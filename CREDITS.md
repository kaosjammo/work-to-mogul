# Credits & third-party assets

## Space Salvage Shooter — Foozle "Void" sprite packs

The **Space Salvage Shooter** mini-game uses pixel art from the Foozle **Void**
series (player ship, enemy fleets, pickups, environment).

- **Author / artist:** Baldur — <https://twitter.com/the__baldur>
- **Distributed by:** Foozle — <https://www.foozle.io> · <https://foozlecc.itch.io/>
- **License:** **CC0 1.0 Universal (Creative Commons Zero — public domain)**
  <https://creativecommons.org/publicdomain/zero/1.0/>
- **License confirmation:** verified from the `Readme.txt` bundled in each pack —
  *"This content is free to use and modify for all projects, including commercial
  projects. Attribution not required."* Attribution is provided here voluntarily.

**Packs used** (provided by the project owner as zips under `art-prompts/`):

- Void — Main Ship (`Foozle_2DS0011_Void_MainShip`)
- Void — Fleet Pack 1 / Kla'ed (`Foozle_2DS0012_Void_FleetPack_1`)
- Void — Fleet Pack 2 / Nairan (`Foozle_2DS0013_Void_FleetPack_2`)
- Void — Fleet Pack 3 / Nautolan (`Foozle_2DS0014_Void_FleetPack_3`)
- Void — Environment Pack (`Foozle_2DS0015_Void_EnvironmentPack`)
- Void — Pickups Pack (`Foozle_2DS0016_Void_PickupsPack`)

The specific files copied into the runtime path (`public/assets/arcade/foozle/`)
and how each is used are documented in [`arcade-assets.md`](arcade-assets.md).

CC0 requires no attribution, so there is no licence-compliance TODO. Because CC0 is
a public-domain dedication, the sprites are free to ship in this commercial-style
project without restriction.

## Other art

All other in-app art (industries, businesses, mascot, VFX, etc.) is project-owned
and catalogued in `src/content/artManifest.ts` / `art-plan.md`. No other
third-party or copyrighted assets are used.
